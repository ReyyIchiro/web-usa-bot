Fitur khusus yang dirancang untuk para modder, developer, dan scripter komunitas GTA San Andreas Multiplayer (MoonLoader, CLEO, dan SA-MP Script).

> ⚠️ **Catatan Penting:** Gunakan semua tools ini secara bijak hanya untuk pengembangan mod legal, perbaikan script sendiri, dan menjaga keamanan komunitas.

---

## `/compilelua` — Compile Lua ke Bytecode

**Deskripsi:** Mengkompilasi file source code `.lua` menjadi file bytecode `.luac` menggunakan engine **LuaJIT**.
- Membantu kamu membagikan mod tanpa memperlihatkan source code mentah
- Setiap file otomatis melalui pemindaian malware sebelum dikompilasi demi keamanan server

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `file` | Attachment | Ya | Upload file script `.lua` kamu (Maks. 500KB) |

---

## `/decompilelua` — Decompile Bytecode ke Kode Terbaca

**Deskripsi:** Mendekompilasi file bytecode `.luac` kembali menjadi source code Lua yang dapat dipelajari.
- Sangat berguna untuk kamu yang kehilangan source code asli mod lama
- Membantu kamu membedah struktur script untuk mencari bug atau error in-game

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `file` | Attachment | Ya | Upload file bytecode `.luac` (Maks. 500KB) |

---

## `/obfuscate` — Proteksi Kode Script

**Deskripsi:** Mengamankan file script Lua kamu dengan mengacak nama variabel, fungsi, dan string agar tidak mudah dibajak atau diubah tanpa izin.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `file` | Attachment | Ya | Upload file `.lua` yang ingin kamu lindungi |

---

## `/deobfuscate` — Rapikan & Bersihkan Kode

**Deskripsi:** Membersihkan format hex escape dan merapikan indentasi kode script yang teracak untuk kebutuhan inspeksi keamanan.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `file` | Attachment | Ya | Upload file script yang ingin kamu analisa |

---

## `/scan` — Scan Malware File Mod

**Deskripsi:** Punya file mod dari internet dan ragu apakah aman? Upload file mod kamu ke `/scan` sebelum dipasang ke folder GTA San Andreas.
- **Format yang Didukung:** `.lua`, `.luac`, `.cs` (CLEO), `.asi`, `.dll`, dan `.sf` (SAMPFUNCS)
- **Deteksi:** Pola Discord webhook stealer, keylogger, trojan downloader, dan backdoor script
