title: Admin & Konfigurasi Server
description: Panduan command admin, GUI dashboard, setup channel otomatis, dan konfigurasi bot Discord USA Core.
---

Semua command di bawah dirancang dengan filosofi **100% GUI-Driven** — kamu gak perlu repot edit file config atau copy-paste ID channel/role. Cukup gunakan menu dropdown, modal formulir, dan tombol interaktif langsung di Discord.

Sebagian besar command ini membutuhkan izin **Administrator** atau **Manage Server**.

---

## Panel Kontrol & Hub Utama

### `/panel`
**Deskripsi:** Membuka master control panel admin untuk mengontrol konfigurasi bot secara visual.

### `/modpanel`
**Deskripsi:** Dashboard moderasi interaktif. Lakukan tindakan Ban, Kick, Timeout/Mute, Warn, serta lihat riwayat kasus pelanggaran member dalam satu tampilan.

### `/ticket-config`
**Deskripsi:** Panel setup sistem tiket bantuan dan jasa Rekber (Escrow).
- Pilih role Staff & Middleman langsung lewat dropdown
- Tentukan persentase potongan fee rekber
- Masukkan nomor rekening dan upload gambar QRIS pembayaran langsung lewat modal interaktif
- Kirim embed panel tiket ke channel publik hanya dengan satu klik

### `/leveling-hub`
**Deskripsi:** Dashboard master untuk mengelola sistem XP chat, role rewards, ekonomi, dan minigames komunitas.

### `/premium-hub` & `/premium`
**Deskripsi:** Panel kontrol lisensi premium untuk owner server: cek masa aktif, generate voucher key, dan cek status server.

## Setup Channel Otomatis

### `/setup-boombox`
**Deskripsi:** Menyiapkan channel khusus untuk Boombox audio. Di channel ini, member cukup kirim link YouTube/TikTok dan bot otomatis membalas link audio siap pakai untuk `/boombox` in-game SA-MP.

### `/setup-crashlog`
**Deskripsi:** Menyiapkan channel otomatis untuk menganalisa crash game GTA SA-MP. Member tinggal tempel kode crash (misal `0x0040fb80`), dan bot langsung menganalisa mod penyebabnya.

### `/setup-party`
**Deskripsi:** Konfigurasi Terminal Mabar (`/party`). Atur kategori voice/text channel sementara yang otomatis dibuat dan dihapus saat party selesai.

### `/setup-ssrp`
**Deskripsi:** Setup channel khusus untuk generator Screenshot Roleplay (SSRP).

### `/setup-cs`
**Deskripsi:** Setup channel dan panel formulir AI Character Story generator.

### `/setup-booster`
**Deskripsi:** Atur notifikasi otomatis saat ada member yang melakukan Server Boost, lengkap dengan pesan ucapan terima kasih dan banner gambar kustom.

### `/setup-logs`
**Deskripsi:** Menghubungkan log audit A.E.G.I.S (join/leave, edit/delete pesan, update role, dan security scan) ke channel tertentu.

### `/setup-suggest`
**Deskripsi:** Mengaktifkan kotak saran otomatis di mana setiap pesan akan diubah menjadi embed saran dengan tombol upvote dan downvote.

### `/setup-threads`
**Deskripsi:** Mengaktifkan pembuatan thread otomatis di channel showcase mod, screenshot, atau diskusi.

### `/setup-sociabuzz`
**Deskripsi:** Integrasi donasi SociaBuzz. Bot otomatis memberikan role donor dan mengirim notifikasi saat ada donasi masuk via webhook.

## Keamanan & Audit Server

### `/perms`
**Deskripsi:** Permission Audit & Management Suite.
- Scan seluruh role dan channel untuk mendeteksi celah izin berbahaya (seperti izin Administrator yang bocor)
- Buat snapshot backup izin server dan pulihkan kapan saja jika terjadi kesalahan pengaturan

### `/backup`
**Deskripsi:** Sistem backup dan restore struktur konfigurasi bot di server kamu.

### `/purge`
**Deskripsi:** Hapus pesan massal (1–100) dengan filter spesifik: bot, user tertentu, atau pesan yang mengandung kata tertentu.

### `/nickconfig`
**Deskripsi:** Atur kebijakan nama member di server (misal mewajibkan format roleplay `Nama_Karakter` tanpa spasi).

## Utilitas Lisensi & Kuota

### `/redeem [key]`
**Deskripsi:** Masukkan kode lisensi voucher untuk mengaktifkan tier Pro atau Enterprise di server kamu.

### `/quota`
**Deskripsi:** Cek sisa kuota harian bot untuk fitur AI, konversi Boombox, dan scan file mod.
