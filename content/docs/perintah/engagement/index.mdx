## `/giveaway`

**Deskripsi:** Buat giveaway dengan konfigurasi lengkap — durasi custom, multiple winners, dan requirement role.

### Subcommand

#### `/giveaway buat`

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `hadiah` | String | Ya | Hadiah yang diperebutkan |
| `durasi` | String | Ya | Durasi giveaway (e.g., `1h`, `2d`, `30m`) |
| `pemenang` | Integer (1–20) | Tidak | Jumlah pemenang (default: 1) |
| `requirement` | Role | Tidak | Role yang wajib dimiliki untuk ikut |
| `channel` | Channel | Tidak | Channel giveaway (default: channel saat ini) |

#### `/giveaway end`
Akhiri giveaway lebih awal dan undi pemenang.

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `message_id` | String | Ya | ID pesan giveaway |

#### `/giveaway reroll`
Undi ulang pemenang giveaway yang sudah selesai.

### Permission
- **Manage Server** atau role admin

### Tier
**Free**

### Contoh Penggunaan
```
/giveaway buat hadiah:"Upgrade Pro 1 Bulan" durasi:2d pemenang:3 requirement:@Member
```

## `/poll`

**Deskripsi:** Buat polling interaktif dengan multiple choice dan hasil real-time.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `pertanyaan` | String | Ya | Pertanyaan polling |
| `opsi` | String | Ya | Opsi-opsi (pisahkan dengan `;`) |
| `durasi` | String | Tidak | Durasi polling aktif (default: selamanya sampai di-end) |
| `anonim` | Boolean | Tidak | Sembunyikan siapa yang vote (default: false) |

### Permission
Tidak ada.

### Tier
**Free**

### Contoh Penggunaan
```
/poll pertanyaan:"Event apa yang ingin kalian adakan bulan ini?" opsi:"Giveaway;Tournament;Movie Night;Game Session" durasi:7d
```

## `/rolemenu`

**Deskripsi:** Buat dropdown menu interaktif untuk self-assign role.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `judul` | String | Ya | Judul menu role |
| `deskripsi` | String | Tidak | Deskripsi singkat menu |
| `mode` | Choice | Tidak | `single` (hanya bisa pilih 1) / `multi` (bisa pilih banyak, default) |

### Permission
- **Manage Roles** — wajib

### Tier
**Free**

### Contoh Penggunaan
```
/rolemenu judul:"Pilih Game Favoritmu" mode:multi
```
Setelah command, bot membuka modal untuk menambahkan role-role yang tersedia.

## `/ticket`

**Deskripsi:** Sistem ticket support dengan kategori, assignment staff, dan transcript HTML otomatis.

### Subcommand

#### `/ticket setup`
Setup panel ticket di channel yang ditentukan.

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `channel` | Channel | Ya | Channel tempat panel ticket ditempatkan |

#### `/ticket kategori tambah`
Tambah kategori ticket baru.

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `nama` | String | Ya | Nama kategori |
| `emoji` | String | Tidak | Emoji kategori |
| `staff_role` | Role | Tidak | Role staff yang handle kategori ini |

#### `/ticket close`
Tutup ticket dan buat transcript HTML.

### Permission
- **Manage Server** untuk setup
- **Manage Channels** untuk membuat channel ticket

### Tier
- **Free**: 1 kategori ticket
- **Pro**: Unlimited kategori, custom embed panel, webhook transcript

## `/tiktok`

**Deskripsi:** Setup notifikasi otomatis saat akun TikTok yang di-track mulai live atau upload video baru.

### Subcommand

#### `/tiktok tambah`

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `username` | String | Ya | Username TikTok (tanpa @) |
| `channel` | Channel | Ya | Channel Discord untuk notifikasi |
| `tipe` | Choice | Tidak | `live`, `video`, `keduanya` (default) |
| `pesan` | String | Tidak | Pesan kustom untuk notifikasi |
| `ping_role` | Role | Tidak | Role yang di-ping saat notifikasi |

#### `/tiktok hapus`

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `username` | String | Ya | Username TikTok yang dihapus |

#### `/tiktok list`
Tampilkan semua tracking aktif.

### Permission
- **Manage Server** — wajib

### Tier
- **Pro**: Maksimal **3 akun** TikTok per server
- **Enterprise**: Unlimited

### Catatan
Notifikasi live bersifat event-driven via Supabase Realtime — tidak polling.

## `/leveling`
