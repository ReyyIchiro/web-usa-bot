Sistem keamanan **A.E.G.I.S SOC (Security Operation Center)** bekerja tanpa henti di background untuk melindungi server dan warga komunitas kamu dari berbagai ancaman: virus mod, Discord token stealer, serangan raid bot, hingga shortlink phising berbahaya.

---

## `/automod`

**Deskripsi:** Membuka dashboard visual Auto-Moderasi. Kamu bisa mengatur filter kata kotor, proteksi anti-spam pesan beruntun, larangan share link server lain, serta sistem honeypot anti-raid langsung lewat tombol interaktif.

---

## `/autoscan`

**Deskripsi:** Konfigurasi pemindaian file mod otomatis. Setiap kali ada member yang mengunggah file `.lua`, `.luac`, `.cs`, `.asi`, atau `.dll`, bot akan langsung membedah pola kodenya.
- **Deteksi:** Token stealer, keylogger, Discord webhook logger, backdoor, dan downloader tersembunyi
- **Ghost Mode:** Jika aktif, bot menindak file berbahaya dan memberikan peringatan via DM tanpa menimbulkan kepanikan di channel publik

---

## `/setup-crashlog`

**Deskripsi:** (Khusus Admin) Siapkan channel pendeteksi crash game GTA SA-MP.
- Sering kali player GTA SA-MP bingung kenapa game mereka tiba-tiba *Crash to Desktop*
- Dengan fitur ini, member cukup paste kode address crash (contoh: `Exception 0xC0000005 at 0x0040fb80`)
- Bot secara otomatis membaca database crash address SA-MP dan memberi tahu mod animasi, texture, memory limit, atau file cleo mana yang jadi penyebabnya!

---

## `/bypass`

**Deskripsi:** Lewati link pendek iklan atau safelink receh (sfrm.in, ouo.io, exe.io, dll) dalam 1 detik.
- Mengambil link file tujuan yang asli secara instan
- Memeriksa apakah link tujuan mengandung phishing atau malware sebelum diklik member

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `url` | String | Ya | Link shortlink atau safelink yang ingin dilewati |

---

## `/blacklist`

**Deskripsi:** Kelola daftar hitam (blacklist) server. Akun yang terdaftar akan langsung dicekal atau diberi tanda peringatan jika bergabung. Bot juga terhubung dengan Global Blacklist komunitas untuk menyaring scammer lintas server.

---

## `/modpanel`

**Deskripsi:** Dashboard moderasi lengkap untuk staf server. Lakukan tindakan:
- **Ban & Unban** (dengan pencatatan alasan permanen)
- **Kick & Timeout**
- **Warn** (peringatan bertingkat beserta riwayat kasus)
- Semuanya dikendalikan melalui tombol tanpa perlu mengingat sintaks command panjang!

---

## `/perms`

**Deskripsi:** Audit perizinan role server. Fitur ini memindai apakah ada role publik yang tidak sengaja memiliki izin Administrator, Manage Channels, atau Mention Everyone yang berisiko disalahgunakan.
