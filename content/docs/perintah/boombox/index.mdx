---
title: Boombox Audio In-Game
description: Panduan command Boombox untuk konversi audio YouTube, TikTok, SoundCloud, dan Spotify ke format in-game SA-MP.
---

Fitur **Boombox Audio** mengubah link lagu dari berbagai platform menjadi direct stream URL audio HTTP yang siap kamu putar langsung di game GTA SA-MP lewat command `/boombox in-game`.

Engine konversi kami menggunakan arsitektur **Multi-Tier Fast Extraction** (TikWM & InnerTube youtubei.js native) yang sanggup memproses audio dalam 1–2 detik tanpa buffering dan hemat bandwidth.

---

## `/convertbb`

**Deskripsi:** Mengubah link lagu streaming menjadi link audio langsung untuk in-game `/boombox`.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `url` | String | Ya | Link lagu atau video yang ingin kamu konversi |

### Platform yang Didukung
- **YouTube & YouTube Music** — Pemrosesan native tercepat via InnerTube API
- **TikTok** — Ekstraksi kilat via TikWM (~1-2 detik, bypass challenge)
- **SoundCloud** — Audio original berkualitas jernih
- **Spotify & Apple Music** — Ekstrak judul & artis otomatis, disinkronkan ke sumber audio terbaik
- **File Audio Langsung** — `.mp3`, `.wav`, `.ogg`

### Contoh Penggunaan
```
/convertbb url:https://www.youtube.com/watch?v=dQw4w9WgXcQ
/convertbb url:https://vt.tiktok.com/ZSjxxxx/
```

**Hasil Respon Bot:**
```
✅ Boombox Ready!
🎵 Judul: DJ San Andreas Remix Full Bass
⏱️ Durasi: 03:25
🌐 Host: Catbox CDN (Direct High-Speed Stream)

In-Game Link:
https://files.catbox.moe/xxxxxx.mp3

Cara pakai di GTA:
Ketik /boombox di game, pilih set URL, lalu paste link di atas!
```

## `/searchbb`

**Deskripsi:** Gak punya link? Cari lagu langsung di Discord dan dapatkan link audio instan tanpa perlu repot buka browser.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `query` | String | Ya | Judul lagu atau nama artis yang ingin dicari |

### Contoh Penggunaan
```
/searchbb query:Dewa 19 Kangen
/searchbb query:DJ Tiba Tiba Aku Melayang
```

## `/uploadbb`

**Deskripsi:** Punya file rekaman suara, jingle radio server, atau lagu lokal sendiri? Upload langsung ke bot dan dapatkan link boombox-nya.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `file` | Attachment | Ya | File audio format `.mp3`, `.wav`, atau `.ogg` (Maks. 25MB) |

---

## `/setup-boombox`

**Deskripsi:** (Khusus Admin) Buat dedicated channel khusus Boombox. Di channel ini, member server kamu gak perlu ketik slash command — cukup kirim link YouTube atau TikTok apa saja, bot bakal otomatis membalas dengan link audio in-game!

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `channel` | Channel | Ya | Channel Discord yang ingin dijadikan tempat convert otomatis |
