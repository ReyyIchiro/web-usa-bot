Kumpulan fitur yang didesain khusus untuk melengkapi kebutuhan player dan server komunitas GTA San Andreas Multiplayer (SA-MP).

---

## `/ssrp` — SSRP Studio 2.0

**Deskripsi:** Mengubah teks dialog chatlog in-game menjadi Screenshot Roleplay (SSRP) berkualitas tinggi. Font dialog, outline hitam, dan warna teks akan disesuaikan mirip persis dengan tampilan asli GTA San Andreas.

### Cara Penggunaan
Ketik `/ssrp` untuk membuka modal editor interaktif:
1. Upload screenshot background in-game kamu
2. Paste dialog atau chatlog roleplay (mendukung `/me`, `/do`, dialog percakapan, dan tag warna)
3. Pilih posisi teks (kiri atas, kiri bawah, kanan)
4. Bot akan merender gambar final siap posting ke forum atau channel showcase!

## `/createcs` — AI Character Story Generator

**Deskripsi:** Bikin latar belakang cerita karakter roleplay (Character Story) standar forum seperti Jogjagamers (JGRP) atau server RP lainnya dengan bantuan AI pintar. Cerita yang dihasilkan mengalir natural, mendalam, dan tidak kaku seperti robot.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `nama` | String | Ya | Nama lengkap karakter (format: Firstname_Lastname) |
| `asal` | String | Ya | Tempat kelahiran dan kebangsaan karakter |
| `alur` | String | Tidak | Ringkasan singkat alur hidup atau cita-cita karakter |

---

## `/namegen` — Generator Nama Karakter RP

**Deskripsi:** Cari inspirasi nama fiksi realistis berformat `Nama_Karakter` yang sesuai dengan tema karakter yang ingin kamu mainkan.

### Opsi

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `origin` | Choice | Tidak | Pilihan asal: `Amerika`, `Italia`, `Rusia`, `Jepang`, `Meksiko/Latin`, `Inggris` |
| `gender` | Choice | Tidak | `Laki-laki` atau `Perempuan` |

## `/serverinfo` & `/serverdirectory`

**Deskripsi:** Pantau status server SA-MP secara realtime langsung dari Discord.

### Opsi `/serverinfo`

| Nama | Tipe | Wajib | Deskripsi |
|------|------|-------|-----------|
| `ip` | String | Ya | IP Address atau domain server SA-MP |
| `port` | Integer | Tidak | Port server (default: 7777) |

Bot akan menampilkan:
- Nama server & Gamemode
- Jumlah player online saat ini
- Ping / Latency
- Cuaca & waktu in-game
