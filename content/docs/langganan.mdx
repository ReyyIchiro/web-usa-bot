USA Core menggunakan sistem **tier berbasis key** — tidak ada dashboard billing web, tidak ada akun yang perlu dibuat. Semua dikelola langsung melalui Discord.

---

## Tier yang Tersedia

### Free (Gratis Selamanya)
Tidak ada kartu kredit, tidak ada batas waktu. Fitur Free selalu tersedia:
- Automod dasar (spam, link, invite, kata terlarang)
- Giveaway, poll, suggestion box
- Ticket support (1 kategori)
- SSRP manual
- Name generator
- Party matching
- Leveling & minigame
- Boombox (5x/hari)
- Bypass (5x/hari)
- Scan malware (3x/hari)

### Pro
Fitur enterprise untuk komunitas aktif. Harga: hubungi tim melalui [Discord Support](https://discord.gg/CnHuMnpKkV).

Termasuk semua fitur Free ditambah:
- A.E.G.I.S SOC penuh (scan malware + ghost mode)
- Scripter Tools (compile, decompile, obfuscate)
- RTM Marketplace
- AI Chat custom + Character Story
- TikTok notify (3 akun per server)
- Boombox unlimited
- Ticket multi-kategori
- Kuota unlimited di semua fitur berbatas

### Enterprise
Untuk komunitas besar dengan kebutuhan khusus. Semua fitur Pro ditambah:
- Kuota benar-benar tidak terbatas
- Prioritas support langsung dari tim
- Onboarding dan konfigurasi langsung
- SLA uptime 99.9%
- Custom AI persona mendalam
- TikTok notify unlimited

## Cara Redeem Key

### 1. Dapatkan Key

Beli atau dapatkan key melalui:
- [Discord Support Server](https://discord.gg/CnHuMnpKkV) — hubungi admin untuk pembelian
- Event atau giveaway dari tim USA Core
- Referral program (jika aktif)

Key terlihat seperti: `USACORE-XXXX-XXXX-XXXX`

### 2. Gunakan Command Redeem

Di server Discord yang ingin diupgrade, jalankan:

```
/redeem key:USACORE-XXXX-XXXX-XXXX
```

### 3. Konfirmasi Aktivasi

```
✅ Tier Berhasil Diaktifkan!

Server: Nama Server Anda
Tier: Pro
Berlaku: 30 hari
Aktif hingga: 11 Sep 2026

Fitur baru yang diaktifkan:
• A.E.G.I.S SOC
• Scripter Tools
• RTM Marketplace
• AI Custom
• TikTok Notify
```

## Manajemen Key

### Key bersifat Portable

Key **tidak terikat** ke satu server. Anda bisa memindahkannya kapan saja:

1. Gunakan `/redeem [key]` di server baru
2. Tier di server lama otomatis dinonaktifkan
3. Tier di server baru langsung aktif

### Satu Key, Satu Server

Key hanya bisa aktif di **satu server** pada satu waktu. Tidak ada penggunaan bersamaan di 2 server.

### Cek Status Tier

```
/tierinfo
```

Menampilkan:
- Tier aktif
- Tanggal aktif dan kadaluarsa
- Sisa hari
- Penggunaan kuota bulan ini

### Perpanjang Tier

Redeem key baru sebelum kadaluarsa. Jika Anda meredeem key Pro baru saat Pro lama masih aktif, sisa hari dijumlahkan.

## FAQ Langganan

**Q: Apa yang terjadi saat tier kadaluarsa?**
A: Server kembali ke tier Free. Data konfigurasi Pro (automod, ticket, dll.) disimpan selama 30 hari — jika diperpanjang dalam periode ini, konfigurasi langsung aktif kembali.

**Q: Apakah ada refund?**
A: Hubungi tim melalui Discord Support. Kebijakan refund ditentukan case-by-case.

**Q: Bisa transfer key ke orang lain?**
A: Ya. Key adalah string yang bisa dibagikan. Siapapun yang punya key bisa meredeem ke server manapun.

**Q: Apakah ada diskon untuk multiple server?**
A: Ya, hubungi tim untuk harga bundel atau volume discount.
