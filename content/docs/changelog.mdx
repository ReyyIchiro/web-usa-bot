## v3.2.0 — Agustus 2026

### ✨ Fitur Baru
- **RTM Marketplace v2** — Rebuild sistem RTM dengan rekber/escrow resmi dan audit trail untuk reveal identity
- **AI Model Custom** — Setiap server sekarang bisa memiliki AI dengan persona dan knowledge base sendiri
- **TikTok Realtime Notify** — Event-driven via Supabase Realtime, tidak lagi polling-based
- **Party Matching v2** — Mode password, auto-expire party, dan notifikasi ketika party penuh
- **SSRP Auto-Builder AI** — Deskripsikan scene, AI yang build screenshot RP-nya
- **Backup & Restore** — Snapshot konfigurasi server USA Core

### 🔧 Peningkatan
- **SOC heuristik lebih akurat** — Reduced false positives 40%, improved malware signature database
- **Boombox queue lebih cepat** — Response time turun dari ~8s ke ~2.5s rata-rata
- **Ticket transcript** — Format HTML yang lebih baik dengan syntax highlighting untuk kode
- **Embed builder** — Support timestamp, mention, dan custom footer icon
- **Leveling** — Perbaikan bug double XP saat pesan dikirim rapid-fire

### 🐛 Bug Fix
- Fix: TikTok notify tidak mengirim notifikasi jika channel di-rename
- Fix: `/bypass` tidak menangani redirect chain lebih dari 3 hop
- Fix: Automod timeout tidak bekerja jika member memiliki 2+ role yang di-whitelist
- Fix: `/giveaway reroll` memilih pemenang yang sama jika hanya 1 partisipan

### ⚠️ Breaking Changes
- Konfigurasi TikTok tracking lama perlu di-reconfigure ulang via `/tiktok tambah` karena perubahan arsitektur event-driven
